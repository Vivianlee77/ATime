# ATime v0.1.0

ATime 的首个公开运行版本：统计 Windows 屏幕有效使用时长和各软件前台用时，并在桌面小窗实时展示。

## 下载与启动

1. 下载 **[ATime-v0.1.0-win-x64.zip](https://github.com/Vivianlee77/ATime/releases/download/v0.1.0/ATime-v0.1.0-win-x64.zip)**。
2. 完整解压，进入 `ATime-win-x64` 文件夹，双击 **`ATime.exe`**。
3. 保留全部 DLL 和运行库，无需安装 .NET，无需管理员权限。

面向 **Windows 11 x64**。`Source code` 是源码，不是 Windows 运行包。附件中的 `.sha256` 用于校验 ZIP 完整性；操作说明见 [README](https://github.com/Vivianlee77/ATime/blob/v0.1.0/README.md)。

## 本版功能

- 有效使用时长：默认连续 5 分钟无键鼠操作后暂停，前 5 分钟保留，恢复操作后继续。
- 各软件前台使用统计：后台应用不重复计时，提供今日、近 7 日和近 30 日排行。
- 桌面小窗：今日时分秒、前三应用、拖动、置顶、暂停及详情入口。
- 系统托盘：隐藏与恢复窗口、暂停与恢复统计、退出。
- 本地 SQLite 保存、CSV 导出、清空历史；主动暂停跨重启保留。
- 可切换有效使用与屏幕会话口径；锁屏、显示关闭、休眠及断开期间不计入。

项目、应用与可执行文件统一命名为 **ATime**。新用户数据位于 `%LOCALAPPDATA%\ATime\usage.db`；已有旧版数据库时会兼容沿用 `%LOCALAPPDATA%\ScreenTimeCompanion\usage.db`。升级前请先退出旧版。

## 当前限制

- 当前为核心 MVP，暂不包含登录自启、隐私应用排除规则、深色主题、趋势图、安装器和自动更新。
- 运行包尚未代码签名，Windows 可能显示未知发布者提示。
- Windows 10、ARM64、复杂多屏与混合 DPI、主动锁屏与休眠的硬件矩阵、24 小时稳定性尚未完成验收；RDP 会话不计时。

数据保存在本机，不记录窗口标题、按键内容、网址、剪贴板或截图，无后台联网。
