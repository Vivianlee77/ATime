# ATime v0.1.1

统计页新增「一天的节奏」和每日趋势图，并将新图标统一应用到程序、窗口与系统托盘。

## 下载与启动

1. 下载 **[ATime-v0.1.1-win-x64.zip](https://github.com/Vivianlee77/ATime/releases/download/v0.1.1/ATime-v0.1.1-win-x64.zip)**。
2. 完整解压，进入 `ATime-win-x64` 文件夹，双击 **`ATime.exe`**。
3. 在桌面小窗点击“查看详情”，即可查看新图表；也可用 `ATime.exe --dashboard` 直接打开统计页。

面向 **Windows 11 x64**，已包含 .NET 运行环境，无需安装 SDK 或管理员权限。请保留完整解压目录。附件中的 `.sha256` 用于校验 ZIP；GitHub 的 `Source code` 是源码。

## 相比 v0.1.0 的更新

- **一天的节奏**：今日按小时显示真实使用时长，当前小时以深绿色突出，悬停查看精确时长。
- **每日使用趋势**：近 7 日 / 30 日按天显示，跟随有效使用 / 屏幕会话口径切换；无记录时留空。
- **历史与实时数据衔接**：已有记录直接生成图表，未保存增量实时显示；重复保存不会重复累计。保留跨小时、跨日、时钟变化和夏令时处理。
- **统一图标**：EXE、窗口、系统托盘、小窗与统计页使用新的 ATime 标识。
- **统计页入口**：`--dashboard` 在程序已运行时也能唤起统计页。
- 修复 30 日趋势的日期标签省略问题。

有效使用时长仍默认在连续 5 分钟无键鼠输入后暂停累计。桌面小窗、各软件统计、暂停/恢复与 CSV 导出继续保留。

## 从旧版升级

先从系统托盘退出旧版，再完整解压并运行新版。已有历史和设置自动沿用，**不需要清空或迁移数据库**。数据通常位于 `%LOCALAPPDATA%\ATime\usage.db`；存在旧版数据时继续兼容 `%LOCALAPPDATA%\ScreenTimeCompanion\usage.db`。若新版解压位置不同，请同步修改自己的桌面快捷方式目标。

## 验证与边界

- Windows Release 构建与 64 项自动检查（33 项计时、22 项存储、9 项输入时间转换）通过。
- 小时合计与应用合计一致；暂停、恢复、重启、导出、清除以及今日/7日/30日图表已有验证记录。
- 运行包为自包含 ZIP，附 SHA-256；未配置代码签名，Windows 可能显示未知发布者提示。
- 登录自启、隐私应用排除规则、深色主题、安装器与自动更新尚未实现。Windows 10、ARM64、混合 DPI 多屏及 24 小时稳定性尚未完成验收；RDP 会话不计时。

统计数据保存在本机，不采集窗口标题、按键内容、网址、剪贴板或截图，无后台联网。
